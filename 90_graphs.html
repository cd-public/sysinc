Objective

  2. Create an API to read edges from a .tsv file into your data structure.
  3. Implement a node data structure.
  4. Populate your node data structure from your edge data structure.
  5. Implement Dikjstra’s algorithm over your node data structure.

I completed 1, 2, and 4 in 90 minutes. 4 was difficult as I was using a char * to store all node data then query the edges, so I added (3) for you.

Gemini was moderately helpful for this and you would be welcome to use it for this type of assignment, but you are responsible for ensuring e.g. every malloc has a corresponding free and all file pointers are closed and etc. etc..

# Objective

1. Implement an edge data structure.
2. Create an API to read edges from a .tsv file into your data structure. 
3. Implement a node data structure.
4. Populate your node data structure from your edge data structure.
5. Implement Dikjstra's algorithm over your node data structure.

I completed 1, 2, and 4 in 90 minutes. 4 was difficult as I was using a `char *` to store all node data then query the edges, so I added (3) for you.

Gemini was moderately helpful for this and you would be welcome to use it for this type of assignment, but you are responsible for ensuring e.g. every `malloc` has a corresponding `free` and all file pointers are closed and etc. etc..

## The `edge_t`

This was my `edge_t`. There is one obvious optimization I did not use, but should have, and you are welcome to modify it, I just wanted you to see what I'm working with.

```{.c filename="dijkstra.c"}
typedef struct edge_struct {
    char src[3];
    char dst[3];
    uint32_t mi;
    uint32_t name;  /* interstate # */
} edge_t;
```
